# 工作生活

一个**只在自己电脑上运行**的私人工作生活管理器：双击图标打开，界面像网页，
数据全部存在本机 —— 不联网、不登录、不同步、不上传。

> 个人自用工具，界面文案与代码注释均为中文。

---

## 一、它能做什么

| 模块 | 状态 | 说明 |
|---|---|---|
| 首页总览 | 可用 | 今日计划、需要你关注的三张卡（逾期 / 复习到期 / 读书进度） |
| 计划 | 可用 | 今天 / 本周 / 月 / 年 / 全部五个视图；单元格日历；任务可标记完成、放弃、重复、复习 |
| 学习 | 可用 | 主题 → 资料 → 章节 → 笔记的四层树，卡住进度、带学习进度 |
| 复习 | 可用 | 间隔复习（1/3/7… 天）、就地背卡、每张卡最近 50 次历史、来源档可隐藏 / 删除 |
| 读书 | 可用 | 书架 + 章节树、书内进度、摘录转复习卡 |
| 备忘录 | 可用 | 标签、置顶、富文本、多行输入 |
| 数据与设置 | 可用 | 回收站（7 天 / 30 天 / 永久）、操作指南、快捷键自定义、备份与导出 |
| 项目 / 预研 / 记账 | 待开发 | 导航里灰显，点进去是说明卡 |

界面是同一套三段骨架：**上预览 / 中两块 / 下树**；树里的节点支持上移 / 下移 /
升一级 / 降一级，也支持拖拽。

## 二、技术栈

- **Electron 44** + **React 19** + **TypeScript 5.9**（主进程 / 预加载 / 渲染三层分离）
- **Vite 8** 打包渲染进程，**Vitest 5** 跑单元测试
- **electron-builder 26** 打 Windows 免安装版（不写注册表、不需要管理员权限）
- 运行时**零第三方依赖**：主进程只用 Node 与 Electron 自带能力

## 三、快速开始

要求 Windows + Node.js 20 以上（本项目在 Node 24 上开发）。不需要 WSL、Python 或数据库。

```powershell
pnpm install
pnpm run binaries   # 补齐 Electron 运行时（走国内镜像 + SHA-256 校验）
pnpm run dev        # 构建后启动应用
```

`.npmrc` 里刻意设了 `ignore-scripts=true`：安装依赖时不执行任何生命周期脚本，
需要二进制的依赖统一由 `scripts/fetch-binaries.mjs` 显式补齐。

## 四、常用命令

| 命令 | 作用 |
|---|---|
| `pnpm run dev` | 构建后启动应用 |
| `pnpm run build` | 类型检查 + 编译主进程 + 打包渲染进程 |
| `pnpm test` | 单元测试（58 个文件 / 1196 项） |
| `pnpm run typecheck` | 只做类型检查（主进程 / 渲染 / 测试三个工程） |
| `pnpm run verify` | 启动真实应用跑端到端验收（分趟、出机器可读报告） |
| `pnpm run package` | 打包成免安装版 exe |
| `pnpm run verify:packaged` | 对打包产物跑同一套验收 |
| `pnpm run smoke` | 冒烟：能开窗、能读写数据即退出 |

## 五、数据存在哪

**打包后的程序**（默认）：

```
%APPDATA%\工作生活\
├─ data\      各模块数据文件（JSON）
├─ backups\   每日备份（保留最近 30 天）
├─ exports\   你主动导出、以及"清空前自动备份"的副本
├─ logs\      启动与错误日志（不记录你的内容）
└─ .runtime\  Chromium 运行期缓存（不含你的数据）
```

- **开发态**：数据放在项目根目录下的 `data\`
- **便携模式**：设 `WORKLIFE_ROOT` 指向想要的目录即可，数据跟着程序走

数据安全靠四层：**原子写入**（先写临时文件再替换）、**启动自检**（主文件坏了回退 `.bak`）、
**每日备份**、**单实例锁**（不会同时开两个窗口写同一份数据）。

## 六、隐私与隔离

这个程序是刻意做成"什么外部的东西都不碰"的：

- 不监听任何网络端口（界面与主进程走 Electron 内部通道）
- 渲染进程里连 `fetch` 一个外部地址都会被拒绝
- 拒绝所有系统权限申请（摄像头、麦克风、定位、通知…）
- 数据只写在上面说的应用根目录内，不往桌面写任何文件

验收时会对比"启动前 / 运行中"的本机端口快照，确认新增监听为 0。

## 七、目录结构

```
src\
├─ main\            主进程（Node 侧）
│  ├─ data\         数据层：原子写入、防抖、自检、备份、导出导入
│  ├─ diagnostics\  端口快照等诊断
│  ├─ verify\       端到端验收场景（分阶段累积）
│  ├─ ipc.ts        界面与主进程之间的通道注册
│  ├─ security.ts   安全策略：拒绝一切外部网络请求与权限申请
│  └─ window.ts     窗口创建
├─ preload\         contextBridge 暴露给界面的接口
├─ shared\          主进程与界面共用的类型与纯逻辑
│                   （`guide.ts`＝应用内操作指南正文源头 · `tree*.ts`＝树与进度 · `date.ts`＝日期）
└─ renderer\        界面（React）
   ├─ shell\        外壳：导航、页头、抽屉、对话框、搜索、角标、三段骨架
   ├─ modules\      各模块页面（plan / calendar / learning / review / reading / memo / settings）
   ├─ styles\       全局样式
   └─ lib\          热键、主题、数据客户端

scripts\            构建、测试、打包、验收脚本（纯 Node，无 CLI 依赖）
tests\              单元测试（Vitest）
```

> 设计 / 需求 / 交接文档属于内部资料，**不随本仓库发布**（见 `.gitignore` 第一节）。
> 其中《操作指南》的正文源头是 `src\shared\guide.ts`，应用里直接渲染它；
> `node scripts\export-guide.mjs` 会把同一份正文导出成 Markdown，供本地比对。

## 八、打包

```powershell
pnpm run package
```

产物在 `pack-<时间戳>\`：

- `工作生活-免安装版-0.1.0.exe` —— 单文件，双击即用
- `win-unpacked\工作生活.exe` —— 未打包目录，可直接运行

打包脚本对本机环境做了若干针对性处理（不用管道 stdio、预解压 Electron 运行时、
单独取一份 7za、直接生成图标），细节在 `scripts/` 各脚本的注释里。这些处理只影响
打包流程，不改变程序行为。
